Preview and production share execution slots and the daily allowance. Each command reserves its full time limit; unused time is refunded when it finishes. Interrupted commands may remain charged at their full reservation. Remaining time does not promise a number of commands.

When all slots are occupied, try again shortly. When allowance is insufficient, retry after reservations are released or the daily reset. There is no waiting queue or fairness guarantee.

Approximate browsers means browsers with visible keyboard, pointer, or command activity in the last 15 minutes. Multiple tabs count together where browser storage is available; this is not a count of people or accounts.

Python help and limits

Start with from bibref.tools import *. Use text1/2, latintext1/2, lookup1/2, raw1/2, find1/2, maxresults, jaccard, jaccard12, nearest12, getrefs_maxlength and latin_to_greek. Numbered functions also have their original _n forms. find1/2 returns passage/start/end lists; distances retain the original wrapper’s scaling.

Restore indentation when pasting from a PDF. text1/2 accepts Unicode Greek and the book’s Greek-font notation (Farec → Φαρες, q → χ, j → θ). Use latintext1/2 for bibref’s internal encoding.

Standard library modules bundled with Python are available; package installation, server files, processes, network access and input() are unavailable. Only run code you trust: scripts execute on your device and can exhaust their own tab’s memory.

Limits: 64 KiB script, 256 bibref operations, 12 minutes and 2 MiB output/results. Search result limit: 10,000. Server capacity and the daily execution allowance are shared with Terminal. Drafts stay in this browser; scripts are never sent to the server.
